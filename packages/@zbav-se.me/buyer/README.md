# @zbav-se.me/buyer

Buyer-specific functionality for the zbav-se.me platform.

## Structure

This package contains buyer-related components, hooks, and utilities that can be imported using the module export pattern:

```typescript
// Import from specific modules
import { something } from "@zbav-se.me/buyer/some-module";

// Import UI components
import { SomeComponent } from "@zbav-se.me/buyer/ui/some-component";
```

## Dependencies

- `@zbav-se.me/common` - Shared common functionality
- `@zbav-se.me/sdk` - API SDK
- `@zbav-se.me/ui` - Shared UI components
- `@use-pico/client` - Client-side utilities
- `@use-pico/common` - Common utilities
