## UI Implementation Details

### 1. History List (`src/user/agent/ui/Agent/HistoryList/`)

**Input**: `AgentInputItem[]` from `withAgentStreamItemsQuery` (server already persists messages)

**Rendered as**:
- `UserMessage` - user's messages
- `AssistantMessage` - assistant's messages (text + tool calls)
- `SystemMessage` - system messages

**State**: Read-only, static from server query (auto-updates via query)

### 2. Live Stream (`src/user/agent/ui/Agent/LiveList/`)

**Input**: Real-time events from `useAgent` hook

**Event Processing**:

| Event | UI Action |
|-------|-----------|
| `response.queued` | Show queued state (optional) |
| `response.created` | Initialize new response |
| `response.reasoning_text_delta` | Show thinking state (spinner + text) |
| `response.reasoning_text_done` | Hide spinner |
| `response.content_part.done` | Content part complete |
| `response.text_delta` | Append text to current message |
| `response.text_done` | Text content complete |
| `response.tool_call.created` | Create tool call block with spinner |
| `response.tool_call.done` | Show input + output, remove spinner |
| `response.tool_call.progress` | Update tool call (ignored for MVP - just show final) |
| `response.output_item.done` | Finalize current message |
| `response.completed` | Move live message to history |
| `response.failed` | Show error message in chat |
| `response.error` | Show error message in chat |

### 3. Reasoning Display

**Requirement**: "Agent is thinking" + spinner (disappears after completion, no summary)

**Implementation**:
- On `response.reasoning_text_delta`: Show `SpinnerContainer` with `translator.text('Agent is thinking')`
- On `response.reasoning_text_done`: Hide spinner completely

### 4. Tool Call Display

**Requirement**: Show input + output, spinner during execution

**Implementation**:
- `response.tool_call.created`: Create block, show spinner
- Wait for tool execution (agent internal)
- `response.tool_call.done`: Show final input (JSON) + output
- Structure:
  ```
  Tool Call: <tool_name>
  ├─ Input: { ... }
  └─ Output: { ... }
  ```

**User Decision**: Show just final result (input + output), no streaming deltas

### 5. Error Handling

**Requirement**: Show errors in chat as messages

**Implementation**:
- `response.failed`: Extract error from response, render as error message
- `response.error`: Render as error message
- Error message format: Red text with error details

## State Management

**Decision**: Use `@lib/client/query/withQuery.tsx` with `useSet()` for granular updates (existing helper)

### Live State via withQuery:

**Approach**: Use `useSet()` from withQuery for direct cache manipulation without re-renders

```typescript
// Agent live state stored in query cache under ['agent', 'live'] key
interface AgentLiveState {
  currentMessage: {
    id: string;
    role: "assistant";
    content: string;
    contentParts: ContentPart[];
  } | null;
  
  isThinking: boolean;
  toolCalls: Map<string, ToolCallState>;
  error: string | null;
}
```

**Usage in useAgent hook**:
- On event: call `useSet()` to update only changed parts via `queryClient.setQueryData()`
- Components use selector pattern to subscribe only to specific state slices

**Key principle**: Only update changed parts (deltas), don't re-render entire UI

### Component Updates (via withQuery useSet):
- Text delta → append to current message content
- Reasoning delta → update reasoning display
- Tool call created → add to toolCalls array with pending state
- Tool call done → update toolCall with input/output
