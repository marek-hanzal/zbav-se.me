## Architecture

### Data Flow

```
useAgent (hook)
  ├─ Streams SSE events from server
  ├─ Parses OpenAI raw events
  └─ Processes each event via onEvent handler (line 59)
       ↓
  TanStack Query cache ['agent', 'live']
       ↓
  Components subscribe to live state slices
       ↓
  UI renders incrementally
```

### Component Tree

```
AgentPage
  └─ AgentMessageList (container with scroll)
       ├─ HistoryList           ← Past messages from withAgentStreamItemsQuery
       │   ├─ UserMessage
       │   ├─ AssistantMessage
       │   └─ SystemMessage
       └─ LiveList              ← Current stream from useAgent hook
           ├─ ThinkingIndicator (spinner + "Agent is thinking")
           ├─ ToolCallBlock     (input/output JSON)
           └─ LiveMessage       (current assistant text)
```

### State Shape

```typescript
// Stored in query cache under ['agent', 'live']
interface AgentLiveState {
  currentMessage: {
    id: string;
    role: "assistant";
    content: string;
    contentParts: ContentPart[];  // for complex types
  } | null;

  isThinking: boolean;
  thinkingText: string;

  toolCalls: Map<string, {
    id: string;
    name: string;
    input: object | null;
    output: object | null;
    isComplete: boolean;
  }>;

  error: string | null;
}
```

## Implementation Steps

### 1. Extend useAgent Hook
**File**: `src/user/agent/hook/useAgent.ts` (line 59)

In `onEvent` handler, integrate with TanStack Query:
- Extract event type + data
- Call `useQueryClient().setQueryData(['agent', 'live'], (prev) => {...})`
- Handle all 20 event types per plan table
- Append text deltas to current message
- Update reasoning spinner state
- Track tool calls with spinner → final state transition

**Key events to handle**:
- `response.queued` → Initialize response
- `response.reasoning_text_delta` → Set `isThinking: true`
- `response.reasoning_text_done` → Set `isThinking: false`
- `response.text_delta` → Append to `currentMessage.content`
- `response.tool_call.created` → Add to `toolCalls` with `isComplete: false`
- `response.tool_call.done` → Update toolCall, set `isComplete: true`
- `response.failed` / `response.error` → Set error message
- `response.completed` → Finalize message, move to history

## Implementation Notes

### Imports & Dependencies

- `@openai/agents` → `AgentEvent`, `AgentInputItem`
- `@openai/agents-core` → `AgentInputItem` type
- `@tanstack/react-query` → useQueryClient, useQuery
- `lib/client` → Container, SpinnerContainer
- `ts-pattern` → match/P for type-safe dispatching
- Existing translator for i18n

### Event Processing Rules

1. **Text deltas**: Append to current message (preserve whitespace)
2. **Tool calls**: Map by tool call ID for state tracking
3. **Reasoning**: Only show spinner, no text display (per plan)
4. **Errors**: Extract error.message or use generic message
5. **Completion**: Move live message to history (query invalidation)

### Selector Pattern (React Query)

```typescript
const useAgentLive = () => {
  const queryClient = useQueryClient();
  return queryClient.getQueryData(['agent', 'live']) as AgentLiveState | undefined;
};

// In component:
const state = useAgentLive();
if (!state) return null;

// Only re-renders when specific selector changes
const isThinking = state.isThinking;
```
