title: Workflow - Novinky/Celkový přehled
summary: Pracovní postup, jak pro uživatele sestavit celkový přehled - zprávy, activity, jeho inzeráty a pod.
---

Toto je odpověď na celkový přehled uživatele z pohledu obou rolí (jak kupující, tak prodejce)

Zdroje:
- activity(priority: high)
- transactions (kolekce)
- seller listing count

Výstup:
- Nový activity + detail
- Nové nezpracované zprávy (souvisí i s activity) + náhled zpráv a inzeráty, kam patří
- Prodávané inzeráty (titulky, max 5.)
