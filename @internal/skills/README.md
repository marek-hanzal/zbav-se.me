- `zbav-sdk-wrapper`
- `zbav-app-component`
- `zbav-data-ui-normalizer`

## Usage note
Codex discovers active skills from `$CODEX_HOME/skills`.
Use symlinks from `$CODEX_HOME/skills/<skill-name>` to this folder so the repo stays the single source of truth.
